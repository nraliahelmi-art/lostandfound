Campus Lost & Found

Project Description
- Campus Lost & Found is a responsive web application designed to help university students and staff report, track, and recover lost or found items across campus. It provides a centralized platform to submit item reports, browse verified listings, and monitor recovery statistics through a clean and accessible interface.

Features
- User Authentication: Register a new account or sign in using the built-in Quick Login demo buttons.
- Interactive Dashboard: View summary metrics (Total, Lost, Found, and Pending reports), a visual breakdown chart, and recent submissions.
- Item Reporting: Submit lost or found item reports with categories, campus locations, dates, descriptions, and optional image uploads (up to 2MB).
- Search & Browse Board: Search verified items by keyword and filter results by status (Lost/Found) or category, with a modal popup for full details.
- Admin Management Panel: Monitor all reports, search entries, and approve, reject, or delete submitted listings.

Frameworks and Libraries Used
- Core Technologies: HTML5, CSS3, and Vanilla JavaScript
- Bootstrap 5.3.3: Responsive grid system, navigation, forms, tables, and modals
- Bootstrap Icons 1.11.3: Clean UI iconography across all pages
- Chart.js 4.4.3: Data visualization for the dashboard reports breakdown

How to Access
- Download or clone the project repository to your local machine.
- Ensure all HTML files (index.html, register.html, dashboard.html, report_items.html, items.html, admin.html) remain in the same directory as the css/ and js/ folders.
- Open index.html in any modern web browser to start using the application.
